# Documentation Overview

This directory contains all documentation for the Morning Goal project, organized by domain.

## 📂 [00_product](./00_product/)
**Product Requirements, UI/UX Philosophy, and Design Guidelines.**
*   `PRD.md`: Product Requirements Document.
*   `UX_Philosophy.md`: Core design philosophy ("Digital Deep Breath").
*   `UI_StyleGuide.md`: Colors, fonts, and component specifications.
*   `UI_Interaction_Improvements.md`: Detailed interaction refinements.

## 🏗 [01_architecture](./01_architecture/)
**Technical architecture, system design, and updatable model strategies.**
*   `Technical_Overview.md`: High-level technical stack.
*   `Mobile_Updatable_Architecture.md`: "Base + Updatable" model architecture.
*   `General_Model_Import.md`: Importing models into the system.

## 🧠 [02_training](./02_training/)
**BERT optimization, pruning, distillation, and GPU usage workflows.**
*   `01_Optimization_Flow.md`: Complete flow for pruning and distilling BERT.
*   `02_GPU_Usage.md`: GPU resource management during training.
*   `03_Student_Model_Use_Cases.md`: Specific use cases for student models.
*   `MobileBERT_Analysis.md`: Technical analysis of MobileBERT.

## 🚀 [03_deployment](./03_deployment/)
**iOS integration, CoreML conversion, and on-device deployment guides.**
*   `CoreML_Pipeline.md`: Designing the CoreML inference pipeline.
*   `Conversion_ONNX_CoreML.md`: Scripts and steps for model conversion.
*   `iOS_OnDevice_Update_Plan.md`: Strategy for updating models on user devices.
*   `iOS_Guides/`: Specific iOS implementation details.

## 📚 [04_guides](./04_guides/)
**Specific scenarios, deep dives, and legacy technical series.**
*   `Technical_Series/`: The original "From Zero to Hero" technical series.
*   `Dev_Pipeline_Guide.md`: CI/CD and automation pipeline guide.
*   `Scenario_*.md`: Specific implementation scenarios (Text Insight, On-Device Training).

## 📦 [resources](./resources/)
**Generated reports, HTML visualizations, and PDFs.**
*   `BERT_research.html`: Interactive visualization of BERT research.
*   `BERT_Mobile_Deployment.pdf`: PDF version of the deployment guide.
