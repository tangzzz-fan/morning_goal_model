# 模型训练触发机制与调试指南

## 当前训练触发机制

### 自动训练触发条件

模型训练由 `ModelUpdateScheduler` 管理,需要同时满足以下**所有条件**:

#### 1. 数据条件
- ✅ **最少纠正样本**: >= 10 个
- ✅ **时间间隔**: 距离上次训练 >= 24 小时

#### 2. 设备条件
- ✅ **充电状态**: 设备正在充电或已充满
- ✅ **电量要求**: >= 50%
- ✅ **低功耗模式**: 未启用

### 触发流程

```
用户纠正预测
    ↓
保存为训练样本 (isTrainingSample = true)
    ↓
累积到 10+ 个样本
    ↓
等待 24 小时 + 设备充电
    ↓
后台任务自动触发
    ↓
执行训练 → 保存模型 → 标记样本已处理
```

### 手动触发

使用 `ModelUpdateScheduler.shared.triggerUpdateImmediately()` 可以绕过条件检查立即触发训练。

## 模型调试界面使用指南

### 功能概览

新增的 `ModelDebugView` 提供以下功能:

#### 1. 📊 模型信息
- 查看模型加载状态
- 查看待训练样本数量
- 了解训练阈值和间隔

#### 2. 🔮 预测测试
- **输入文本**: 手动输入或使用快速填充
- **运行预测**: 实时查看模型推理结果
- **查看结果**: 分类、情感及置信度
- **保存纠正**: 如果预测不准确,可以纠正并保存为训练样本

#### 3. 🎓 训练控制
- **查看样本数**: 当前待训练样本数量
- **立即训练**: 无需等待条件,直接触发训练
- **训练日志**: 实时查看训练过程

### 使用步骤

#### 步骤 1: 添加调试入口

在你的应用中添加调试菜单入口:

```swift
#if DEBUG
@State private var showModelDebug = false

// 在某个视图中添加
Button("模型调试") {
    showModelDebug = true
}
.sheet(isPresented: $showModelDebug) {
    ModelDebugView()
}
#endif
```

#### 步骤 2: 测试预测

1. 打开 **模型调试** 界面
2. 在 **预测测试** 区域输入文本
3. 点击 **运行预测**
4. 查看预测结果和置信度

#### 步骤 3: 纠正错误预测

如果预测不准确:
1. 在结果下方选择 **正确分类** 和 **正确情感**
2. 点击 **保存纠正**
3. 样本会被保存为训练数据

#### 步骤 4: 触发训练

当积累了足够的纠正样本:
1. 展开 **训练控制** 区域
2. 查看当前样本数量
3. 点击 **立即训练**
4. 观察训练日志

#### 步骤 5: 验证训练效果

训练完成后:
1. 重新输入相同的文本
2. 运行预测
3. 查看模型是否学习了纠正

## 常见问题

### Q: 为什么自动训练没有触发?

**A**: 检查以下条件:
- [ ] 是否有 >= 10 个纠正样本?
- [ ] 距离上次训练是否 >= 24 小时?
- [ ] 设备是否正在充电?
- [ ] 电量是否 >= 50%?
- [ ] 是否未开启低功耗模式?

**解决方案**: 使用调试界面的"立即训练"功能绕过条件检查。

### Q: 训练后预测结果没有变化?

**A**: 可能原因:
1. 训练样本数量太少 (< 10)
2. 训练数据质量不高
3. 模型未正确重新加载

**验证方法**:
1. 查看日志确认训练成功
2. 查看 `Documents` 目录是否有 `student_sequence_classification.mlmodelc`
3. 重启应用,查看是否加载了更新后的模型

### Q: 如何重置模型到初始状态?

**A**: 删除 Documents 目录中的 `student_sequence_classification.mlmodelc` 文件,应用会重新加载 Bundle 中的原始模型。

### Q: 训练需要多长时间?

**A**: 取决于样本数量和设备性能:
- 10-20 个样本: 约 10-30 秒
- 50+ 个样本: 约 1-2 分钟

## 最佳实践

### 1. 数据质量
- ✅ 确保纠正的标签是正确的
- ✅ 提供多样化的训练样本
- ✅ 避免重复的训练数据

### 2. 训练频率
- ✅ 不要过于频繁训练 (建议间隔 >= 1 小时)
- ✅ 积累足够的样本再训练 (>= 10 个)
- ✅ 定期验证训练效果

### 3. 性能监控
- ✅ 观察推理时间 (应 < 100ms)
- ✅ 检查置信度分布
- ✅ 记录训练前后的准确率变化
